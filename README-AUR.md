# Eisenhower Matrix - AUR Package

A GUI tool for task prioritization using the Eisenhower Matrix method.

## Installation

Install from AUR using your preferred AUR helper:

```bash
# Using yay
yay -S eisenhower-matrix

# Using paru
paru -S eisenhower-matrix

# Using pikaur
pikaur -S eisenhower-matrix

# Manual installation
git clone https://aur.archlinux.org/eisenhower-matrix.git
cd eisenhower-matrix
makepkg -si
```

## Usage

After installation, you can launch the application from your application menu or run:

```bash
eisenhower-gui
```

## Dependencies

- python>=3.9
- python-gobject
- gtk4
- libadwaita
